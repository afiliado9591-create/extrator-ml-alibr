# Extrator ML — Alibr

Projeto pronto para importar na Vercel.

## Publicação

1. Envie todo o conteúdo desta pasta para um repositório do GitHub.
2. Na Vercel, escolha **Add New → Project** e importe o repositório.
3. Use **Framework Preset: Other** e clique em **Deploy**.

Não configure Build Command nem Output Directory.
